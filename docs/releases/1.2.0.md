# 手机通知 v1.2.0

将 iPhone 通知和手动发送的剪贴板内容带到 Windows 10/11 x64 电脑，手机与电脑通过可互通的局域网连接。

- 通知同步：自定义紧凑卡片、Windows 通知中心、来源 App 图标和本机通知记录；点击通知可定位到对应消息
- 剪贴板与文件：接收文字、图片和文件，历史文字可展开，已收到的内容可重新复制到电脑剪贴板
- 图片预览：支持 PNG/JPEG、HEIC/HEIF 小图及放大预览，HEIC 在本机转换，无需额外安装系统解码扩展；原文件保留
- 桌面配置：通知与剪贴板独立开关、登录自启、共用局域网连接设置和手机配置二维码
- 30 个常用 App 内置图标，以及在线查询和本机缓存

## 下载与安装

下载 **PhoneNotify-1.2.0-win-x64.zip** 并完整解压，运行 `PhoneNotify.exe`；需要桌面快捷方式时运行包内 `install.ps1`。同名 `.zip.sha256` 文件用于校验完整性。Source code 压缩包仅供开发使用。

完整 ZIP 包含 Node.js、图片解码组件及许可。电脑仍需 WebView2 Runtime；手机需要快捷指令和 Scriptable。首次使用请按 README 完成配对和防火墙配置。已有用户的配对配置和历史保存在原数据目录；使用安装脚本升级时保留用户数据，不要删除原数据目录。

## 验证与范围

核心功能已在 Windows 10 19045 上实测，包括 HEIC 预览和图片重新复制；自动测试及 Windows 完整包构建通过后发布。Windows 11、企业策略及不同 iOS 环境仍需相应实机验证，通知自动化以手机实际提供的触发器为准。离开局域网后通知静默跳过，不补发。
