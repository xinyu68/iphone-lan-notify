# 手机通知 v1.2.1

- 「通知静默转发」脚本新增手动测试：在 Scriptable 内直接运行，选择「发送测试通知」，无需另建测试快捷指令
- 测试显示请求接收结果、HTTP 状态或网络错误；地址或令牌不匹配、电脑关闭通知接收时提供对应提示
- 正常快捷指令通知转发保留 2 秒超时和失败静默跳过；测试采用 10 秒超时，并支持取消

## 升级与使用

下载完整 Windows ZIP，按 README 升级。打开电脑应用「手机配置 → 通知同步配置」，重新复制生成的脚本，替换手机 Scriptable 中的「通知静默转发」并保存。快捷指令原有的字典参数和自动化动作不需要修改。旧手机脚本不会自动更新。

在 Scriptable 内直接运行该脚本，点击「发送测试通知」。成功提示表示电脑已接收请求，仍应检查电脑通知记录和卡片是否显示。测试期间请保持手机与电脑在可互通的局域网，并允许 Scriptable 访问本地网络。

保留既有配对配置和用户数据。Windows 10/11 x64、WebView2 Runtime、快捷指令和 Scriptable 的要求不变；不同 iPhone/iOS 环境的菜单及系统授权仍需真机验证。
