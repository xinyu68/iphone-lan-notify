# 手机通知 v1.3.0

- 主界面顶部显示当前版本，Windows 文件属性和托盘提示同步显示版本
- 新增「检查更新」：获取 GitHub Releases 最新正式版，展示更新说明和下载进度
- 支持应用内下载、校验、安装并自动重启；校验未通过不安装，替换或新版本启动失败时尝试恢复旧程序
- 配对地址、令牌、通知记录、剪贴板收件箱、接收偏好和开机自启保留；已有有效 Node.js 路径继续使用，避免改变防火墙对应的程序路径

## 升级

v1.2.x 没有应用内更新入口，首次升级到本版仍需下载完整 Windows ZIP，并按 README 使用安装脚本更新原安装目录。升级到 v1.3.0 后，后续正式版可以在应用内点击「检查更新 → 下载并更新」。

更新从本项目 GitHub Releases 下载，核对附件 SHA-256、校验清单和包内文件清单后替换程序。需要访问 GitHub；受网络或 GitHub 限流影响时可稍后重试或手动下载。更新期间接收服务会短暂退出，离线期间的通知不补发。

手机中已经保存的 Scriptable 脚本不会随电脑程序自动更新，需按版本说明自行替换。通知、剪贴板及 HEIC 预览功能保留。
