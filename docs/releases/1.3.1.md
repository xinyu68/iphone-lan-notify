# 手机通知 v1.3.1

- 更新检查改为下载 Releases 中的公开 `update.json` 版本清单，不再调用匿名 GitHub REST API；普通使用无需 GitHub 账号或访问令牌
- 检查失败时清除旧的“最新版本”和更新说明，避免将历史结果误认为当前最新版
- 明确区分更新文件缺失、HTTP 403 和 HTTP 429，不再统一显示“限制访问”
- 保留 v1.3.0 的版本显示、更新说明、下载进度、校验、备份、失败回滚和自动重启功能

## 使用与升级

旧版本若因 API 额度耗尽而无法检查更新，请先从本 Release 下载完整 Windows ZIP 并按 README 更新原安装目录。升级后使用标题旁的版本号和右上角「检查更新」，发现新版可直接下载安装并自动重启。

Assets 中的 `update.json` 供程序读取，用户只需下载 Windows ZIP；同名 `.sha256` 文件用于校验。更新仍需正常访问 GitHub Releases 下载地址，网络不通时会明确提示，保留当前程序和数据。

手机中已保存的 Scriptable 脚本不会随电脑应用自动替换。
