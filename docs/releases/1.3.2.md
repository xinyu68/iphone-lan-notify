- 保留公开 Releases 更新清单，检查更新无需 GitHub 账号或访问令牌，也不消耗匿名 REST API 的每小时额度
- 修复更新重启后数据目录末尾斜杠导致的重复窗口和点击唤起异常，统一同一数据目录的程序身份
- Windows 安装包下载优先使用系统自带的 curl，显示进度、重试临时网络故障，并继续核对长度与 SHA-256；系统缺少 curl 时使用原下载方式

- 保留版本显示、更新说明、安装前校验、备份、失败回滚及自动重启，保留配对、开机自启和接收记录

## 使用与升级

旧版本如果因 API 额度耗尽或下载超时而无法更新，请先下载本 Release 的完整 Windows ZIP，按 README 更新原安装目录。此后可使用主界面的「检查更新 → 下载并更新」。网络仍须能访问 GitHub Releases；连接失败时程序保留当前版本和数据，并允许稍后重试。

手机中已保存的 Scriptable 脚本不会随电脑程序自动替换。
