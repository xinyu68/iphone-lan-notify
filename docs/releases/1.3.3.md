## 升级提示

使用 v1.3.0～v1.3.2 或更旧版本时，建议先下载本版本完整 Windows ZIP，按 README 更新原安装目录，再使用后续的应用内更新。旧程序运行的是它自身携带的更新脚本，下载新版 ZIP 不会在安装前自动修复旧脚本。

配对、接收开关、开机自启和消息记录保留；手机中已保存的 Scriptable 脚本不会随电脑程序自动替换。下载仍需正常访问 GitHub Releases。
